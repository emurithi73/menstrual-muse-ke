# menstrual-muse-ke
Menstrual Muse is a youth-led advocacy platform in Isiolo &amp; Meru, Kenya, breaking period stigma through menstrual hygiene education, reproductive health talks, school outreaches and sanitary support. We empower girls with knowledge, dignity and confidence so no girl misses school because of her period. Educate. Support. Empower. Let's break stigma.
