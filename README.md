# Menstrual Muse Community Initiative website

A lightweight, semantic three-page static website prepared for Netlify or any static host.

## Pages
- `index.html` - Home, mission, vision, sponsorship, partnership and support calls to action.
- `learn.html` - Learning hub, menstrual health basics, FAQ and Ask Questions email workflow.
- `gallery.html` - Gallery and community-impact presentation.

## Assets
- `assets/brand-logo.png` - extracted brand mark from the supplied Menstrual Muse gallery PDF.
- `assets/Menstrual_Muse_Handbook_V1.pdf` - supplied educator handbook.
- `assets/gallery/` - selected images rendered from the supplied gallery PDF.
